# Sitemap Structure

## Data Source
Navigation is centralized in `lib/navigation/site-map.ts`.

## Visual Routes
- `/sitemap`
- `/mapa-do-site`

## XML Route
- `/sitemap.xml`, generated by `app/sitemap.ts`.

## Sections
- Institucional: `/`, `/sobre`, `/como-funciona`, `/faq`, `/contato`
- Produto: `/roteiros`, `/roteiros/serra-da-misericordia`, `/demo`, `/demo-mobile`, `/demo/status`
- Cadastros: `/cadastro`, `/cadastro/aluno`, `/cadastro/professor`, `/cadastro/guia`, `/cadastro/turista`
- Areas logadas: `/app/aluno`, `/app/aluno/aulas/aula-guia-01`, `/app/professor`, `/app/guia`, `/app/turista`, `/app/admin`, `/app/admin/aprovacoes`
- Transparencia: `/sitemap`, `/creditos-imagens`, `/termos`, `/privacidade`

## Maintenance Rule
When adding/removing major routes, update `lib/navigation/site-map.ts` first, then confirm `/sitemap` and `/sitemap.xml` in browser/build.
