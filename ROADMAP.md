# Roadmap

## Phase 0 - Presentation MVP
- Project scaffold, documentation, design system and navigable mock flows.
- Student dashboard, route showcase, admin metrics, video progress fallback and demo mobile.

## Phase 1 - Functional MVP After Meeting
- Apply Supabase schema and RLS.
- Connect auth, registration, approvals and persisted student progress.
- Replace placeholder brand assets with official PNG/SVG.

## Phase 2 - Version 1
- Full teacher content workflow.
- Route booking pipeline and tourist notifications.
- Real dashboards and exports.

## Phase 3 - Advanced PWA
- Offline-friendly lesson cache.
- Push notifications.
- Better geolocation, map and route sharing.

## Phase 4 - Native App Future
- Reuse domain model and design system.
- Evaluate React Native/Expo after web/PWA validation.

## Phase 5 - Revenue And Reports
- Paid bookings, reservations, guide payout reports and advanced impact dashboards.

## Production Learning Platform Reset
New production blueprint lives in `docs/production-platform/`.

V1 should focus on:
- public enrollment funnel,
- real auth/signup/approval,
- student learning platform,
- teacher workspace,
- admin command center,
- certificates and reports.

Tourism marketplace, guide public profiles and bookings move to later phases after the teaching core is stable.
